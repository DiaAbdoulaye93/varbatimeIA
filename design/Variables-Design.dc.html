Variables de design

Couleurs, typographie, espacements, rayons et ombres, sous forme de variables CSS à placer dans styles.scss. Les valeurs des sentiments ont été vérifiées pour les daltonismes (séparation des paires adjacentes) et pour le contraste du texte (≥ 4,5:1).

Couleurs d'interface

Un seul accent (bleu) réservé aux actions, liens et sélections. Les gris sont légèrement froids.

Rayons et ombres

Rayon 8 px pour tout ce qui se clique ou se saisit, 12 px pour les cartes, pilule pour les badges. Ombres discrètes : la bordure fait l'essentiel du travail.

Fichier de variables CSS

À copier dans src/styles.scss (ou _tokens.scss). Les composants Angular Material reprennent ces valeurs via leurs tokens de thème (ex. --mdc-filled-button-container-shape: var(--radius-md)) ; Chart.js reçoit les couleurs de sentiment dans backgroundColor, dans l'ordre Positif, Mixte, Neutre, Négatif, avec borderColor: #FFFFFF et borderWidth: 2 pour l'espace entre segments.

/* Analyseur de verbatims — variables de design */

  /* Couleurs d'interface */

  --color-primary-strong: #1B3F8F;   /* survol et état actif */
  --color-primary-soft: #E8EEFB;     /* fonds de sélection, chips actives */
  --color-primary-ink: #17347A;      /* texte sur fond primary-soft */
  --color-ink: #16202A;              /* texte principal */
  --color-ink-secondary: #3F4B5A;    /* texte secondaire */
  --color-ink-muted: #5B6776;        /* libellés, aides (4,5:1 sur blanc) */
  --color-ink-disabled: #8A94A1;
  --color-background: #F3F5F8;       /* fond de page */
  --color-surface: #FFFFFF;          /* cartes, tableaux, champs */
  --color-surface-alt: #F8FAFC;      /* en-têtes de tableau, zone de dépôt */
